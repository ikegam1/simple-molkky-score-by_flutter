プライバシーポリシー

Easy Molkky Score（以下「本アプリ」といいます）は、利用者のプライバシー保護を重要視しています。本ポリシーでは、本アプリにおける情報の取り扱いについて説明します。最終更新日：2026 年 7 月 15 日。

1. 収集する情報とアクセスする Google ユーザーデータ

本アプリでは以下の情報を扱います。

1.1 Google Sign-In により取得する情報（任意）

利用者が「Google でログイン」を選択した場合、以下の Google ユーザーデータを取得します。取得する scope は Google 標準の openid / email / profile のみで、他の追加スコープ（Drive / Gmail / YouTube 等）は要求しません。

  • Google アカウントの一意識別子（sub）
  • メールアドレス（email）
  • 表示名（name）
  • プロフィール画像 URL（picture）

1.2 本アプリで利用者が入力する情報

  • プレイヤー名、各ターンの得点、試合開始日時、試合形式などのスコア記録

1.3 自動的に生成される識別子

  • Firebase Authentication が発行する匿名ユーザー ID（Google Sign-In と紐付け後は上記 sub と関連付けられます）

2. 情報の利用目的（Data Use）

  • ユーザー識別と機器間同期：Google Sign-In により取得した sub / email を用いて、複数端末で同じ利用者を識別し、Firestore に保存された試合履歴を同期表示します。
  • 表示用：name と picture はアプリ内で「現在のログインアカウント」を表示するためのみに使用します。
  • 試合履歴の保存・表示：入力されたスコアは Firestore に紐付けて保存し、利用者本人のみが閲覧できます。

取得した Google ユーザーデータは 広告表示、広告配信、信用スコアリング、その他ユーザー体験の提供・改善以外の目的には一切利用しません（Google API Services User Data Policy の Limited Use 要件に準拠）。また AI/ML モデルの学習にも使用しません。

3. 第三者への提供・共有（Data Transfer）

取得した情報は下記以外の第三者に提供・販売することはありません。

  • Google LLC（Firebase Authentication / Cloud Firestore）：認証情報およびスコアデータの保存インフラとして利用します。Google のプライバシーポリシーが適用されます。

データブローカー、広告事業者、その他マーケティング目的の第三者にはデータを譲渡しません。

4. 情報の保護（Data Protection）

  • 通信は HTTPS（TLS 1.2 以上）で暗号化されます。
  • Firebase の保存データは Google のインフラで保存時暗号化されます。
  • Firestore Security Rules により、各利用者は自身の UID に紐付いたスコアデータのみを読み書きできる構成です。他人のデータは一切参照できません。
  • Google のクライアント ID / API キー等の資格情報は Google Cloud Console 上で適切に管理します。

5. データの保存期間と削除（Data Retention & Deletion）

  • スコアデータおよびアカウント連携情報は、利用者が本アプリを継続して利用している間、保存されます。
  • 利用者はいつでも下記連絡先に「アカウント削除希望」と明記の上、Google Sign-In で使用したメールアドレスから連絡することで、当該アカウントに紐付く全データ（Google Sign-In 情報および Firestore 上の試合履歴）の削除を請求できます。連絡受領から 30 日以内に削除対応いたします。
  • Google Sign-In との連携解除（アプリ側からの signOut）を行った場合、以降そのアカウントで新規データが追加されることはありませんが、既存の紐付きデータは上記の削除請求があるまで保持されます。

本アプリの利用によって生じた何らかのトラブルや損失、損害等について、開発者は一切の責任を負いかねます。

本ポリシーの内容は、事前の通知なく変更されることがあります。変更後の本ポリシーは、本ページに掲載した時点から効力を生じるものとします。

Privacy Policy

Easy Molkky Score (hereinafter, the “App”) values the protection of user privacy. This Privacy Policy explains how the App handles user information. Last updated: July 15, 2026.

1. Information Collected and Google User Data Accessed

1.1 Information Obtained via Google Sign-In (optional)

If the user chooses to sign in with Google, the App requests the following Google user data. The scopes requested are the Google-standard openid, email, and profile only. The App does not request any additional scopes (Drive, Gmail, YouTube, etc.).

  • Google account unique identifier (sub)
  • Email address (email)
  • Display name (name)
  • Profile picture URL (picture)

1.2 Information Entered by the User in the App

  • Score records, including player names, per-turn scores, match start time, and match format

1.3 Automatically Generated Identifiers

  • The anonymous user ID issued by Firebase Authentication (after linking with Google Sign-In, it is associated with the sub above)

2. How Information Is Used (Data Use)

  • User identification and cross-device sync: The sub and email obtained via Google Sign-In are used to identify the same user across multiple devices and to display the user’s match history stored in Firestore.
  • Display: name and picture are used solely to display the “currently signed-in account” within the App.
  • Match history storage and retrieval: Scores entered by the user are stored in Firestore, associated with the user, and can only be viewed by that same user.

Google user data obtained by the App is never used for any purpose other than providing or improving user-facing features (advertising, ad targeting, credit scoring, and similar are strictly prohibited), in compliance with the Google API Services User Data Policy including the Limited Use requirements. The data is also never used for AI/ML model training.

3. Data Transfer and Sharing with Third Parties

The App does not sell or transfer user data to third parties, except as follows:

  • Google LLC (Firebase Authentication / Cloud Firestore): Used as the authentication and score-storage infrastructure. Google’s Privacy Policy applies to this data.

The App does not transfer data to data brokers, ad networks, or any other third parties for marketing purposes.

4. Data Protection

  • All communication uses HTTPS (TLS 1.2 or later).
  • Data stored in Firebase is encrypted at rest by Google’s infrastructure.
  • Firestore Security Rules ensure that each user can only read and write score data associated with their own UID. Access to other users’ data is not possible.
  • Google Cloud client IDs and API keys are managed appropriately in the Google Cloud Console.

5. Data Retention and Deletion

  • Score data and account-linking information are retained for as long as the user continues to use the App.
  • Users may request deletion of all data associated with their account (Google Sign-In information and match history in Firestore) at any time by contacting the address below from the email address used for Google Sign-In, with the subject line stating a deletion request. Deletion is completed within 30 days of the request being received.
  • Signing out of Google in the App prevents new data from being added under that account, but existing linked data is retained until a deletion request is received as described above.
