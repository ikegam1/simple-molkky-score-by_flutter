モルックのルールと使い方

Easy Molkky Score — モルックのスコアをかんたんに管理できる無料アプリ

モルックは、木の棒を投げて数字の書かれたピンを倒す、フィンランド生まれのスポーツです。ルールはシンプルですが、50点ちょうどを狙う計算と、超えたら25点に戻される緊張感が独特の面白さを生みます。

このページでは、モルックの基本ルールと、Easy Molkky Score でのスコアの付け方をまとめています。アプリは Web・iOS・Android で無料で使えます。

モルックの基本ルール

モルック（Mölkky）は1996年にフィンランドで生まれました。倒す対象は1から12までの数字が書かれた12本の木製ピン（スキットル）で、これをモルック棒と呼ばれる木の棒を投げて倒します。

得点の数え方

ここがモルック最大の特徴です。倒れた本数によって点数の数え方が変わります。

倒れたピン入る点数
1本だけそのピンに書かれた数字がそのまま点数（例: 12 を倒したら12点）
2本以上倒れた本数が点数（例: 5本倒したら5点）
0本ミス。0点

つまり、大量得点を狙うなら1本だけを正確に狙う必要があります。狙いが甘くて何本も倒すと、かえって点数が伸びません。

50点ちょうどで勝ち

先にちょうど50点に到達したプレイヤーの勝ちです。

50点を超えてしまうと、得点が25点に戻ります。 残り数点というところで大きく倒してしまい、振り出しに近いところまで戻される——これがモルックの醍醐味です。終盤は「何点を狙って投げるか」の駆け引きになります。

3回続けて外すと失格

1本も倒せない投擲が3回続くと失格になり、その試合から抜けることになります。安全に小さい数字を狙うか、勝負に出るかの判断が必要です。

倒れたピンは、その場に立て直す

倒れたピンは元の位置には戻さず、倒れた場所にそのまま立て直します。試合が進むにつれてピンは散らばっていき、狙いにくくなっていきます。

Easy Molkky Score はこれらのルールを自動で処理します。50点ちょうどの判定、超過時の25点への戻し、3回連続ミスによる失格、失格者を飛ばした順番管理——手計算や記憶に頼る必要はありません。最大8人まで登録できます。

試合を始める

  1. プレイヤー名を追加します。一度入力した名前は次回から候補に出るので、いつものメンバーなら選ぶだけです
  2. 試合形式を選びます（後述）
  3. 必要ならターン制限や試合時間制限を設定します
  4. 「ゲーム開始」を押します

サインインは不要です。そのまま始められます。アカウントでログインすると、戦績が別の端末にも引き継がれます。

投げる順番をルーレットで決める

「投げ順ルーレット」をオンにしておくと、試合開始時に順番をランダムに決められます。じゃんけんの代わりに使えます。

点数の入れ方

  • 1本だけ倒れたら、そのピンの番号を押します
  • 複数倒れたら、倒れた本数を押します
  • ミスは 0 を押します
  • 間違えたら「戻る」でひとつ前に戻せます

試合が終わった直後でも、結果画面の「点数を修正する」から直前の投擲に戻って直せます。

37点ルール

大会などで使われることがあるローカルルールにも対応しています。「0（ミス）」を長押ししながら上にフリックすると [25↓] 37点ルール のバッジが出ます。指を離すと、そのとき投げているプレイヤーが37点以上であれば、得点を25点に戻します（1ミスとしてもカウントされます）。対象は手番のプレイヤーだけで、他の人の得点は変わりません。37点未満のときは何も起きず、その旨が表示されます。

投擲の内容を記号で残す

「何点入ったか」だけでなく、どういう狙いが成功したかを残せます。あとで戦績を見返すときに、試合の流れを思い出せます。

操作記録される内容
再タップ（0.3秒以内に同じボタン）◯囲み — 単品狙いの成功
長押し中に上フリック□囲み — 本数ガシャの成功
長押し中に下フリック◯囲み（同上）
長押し中に左フリック寄せ成功（数字に ← を重ねて表示）
長押し中に右フリック飛ばし成功（数字に ↑ を重ねて表示）

付けた記号は、スコア表・戦績・結果カードのすべてに反映されます。

試合形式を選ぶ

形式内容
先取（〇先）決められたセット数を先に取ったほうが勝ち。2先・3先・4先・5先・11先から選べます
セット数固定（〇番）1・2・10セットを戦い、通算で勝敗を決めます
3番（3セット）3セット固定で戦う形式です
ターン制限上限ターンを決めて、終了時点で一番点数が高い人が勝ち。同点トップなら引き分けです
試合時間制限開始後にカウントダウンが始まります。時間切れのとき、そこで終えるか続けるかを選べます

3人・4人で遊ぶときは、人数に応じたセット数（6・9・8・12セットなど）も選べます。

サバイバルルール

多人数で遊ぶとき、失格になったプレイヤーは自動的に順番から飛ばされます。最後の1人になった時点で試合終了です。

1人用モードと100均モード

セルフ5ターン / セルフ6ターン

プレイヤーが1人のときに選べる練習モードです。決められたターン数以内に50点ちょうどを作れたら成功。連続成功回数を伸ばしていく、記録更新型の遊び方です。

100均モード

2セットを使った変則ルールです。1セット目は通常どおり50点を目指します。2セット目は、1セット目との合計で100点ちょうどを狙います。合計が100点を超えると75点に戻ります。

OBS に重ねるライブスコア表示

試合の様子を配信しているとき、視聴者にスコアを見せられます。配信ソフトに重ねて使う、透過背景のスコアボードです。

  1. 試合画面の右上にあるビデオアイコンをタップします
  2. ライブ表示用のURL が発行されます
  3. そのURLを OBS などの「ブラウザソース」に設定します

背景が透明なので、カメラ映像やゲーム画面にそのまま重ねられます。スコアを入力するとリアルタイムで反映されます。

表示される内容

  • プレイヤー名
  • 現在の得点
  • 直近3投
  • ターン数
  • 獲得セット数

公開範囲と有効期限

URLを知っている人は誰でも見られます。パスワードはかかりません。配信のコメント欄などに貼ると、誰でもスコアを追えるようになります。

発行したURLは試合終了から24時間後に自動で削除されます。

入力を速くする

Bluetoothのテンキーを接続すると、数字キーでそのまま入力できます。画面をタップするより速く、手元を見ずに打てます。記録係を置いて試合を回すときに効きます。

キー動作
1〜9ピン番号
0ミス
*10点
−11点
+12点
バックスペース戻る
エンターダイアログを次へ進める

数字キー（0〜9）はPCの通常キーボードでも使えます。ただし 10・11・12 はテンキー専用のキーに割り当てているため、これらを入力するにはテンキーが必要です。

テンキーを繋ぐと、名前が打てなくなることがあります

iPhone・iPadは外付けキーボードが接続されている間、画面のキーボードを表示しません。テンキーには文字キーがないため、プレイヤー名の入力欄をタップしても何も出てこない、という状態になります。故障ではなく、iOSの仕様です。

iPhoneなら、下の設定をしておくと背中を2回叩くだけでキーボードを呼び出せます。一度設定すれば、あとはテンキーを繋いだままで困りません。

背面タップはiPhone専用の機能です（iPhone 8以降）。iPadをお使いの場合は下の「iPad：ショートカットバーから呼び出す」をご覧ください。

iPhone：最初に一度だけ設定する

① 画面のキーボードが出るようにする

  1. 「設定」アプリ →「アクセシビリティ」→「タッチ」を開く
  2. 「AssistiveTouch」を開く
  3. 「ポインティングデバイス」の中にある「オンスクリーンキーボード表示」をオンにする

ここが肝心です。この設定をしていないと、次の手順をやってもキーボードは出ません。AssistiveTouch本体のスイッチは、いまはオフのままで構いません。

② 背面タップで切り替えられるようにする

  1. ひとつ前の「タッチ」の画面に戻る
  2. 一番下までスクロールして「背面タップ」を開く
  3. 「ダブルタップ」を選ぶ
  4. 一覧から「AssistiveTouch」を選ぶ

iPhone：使いかた

  1. テンキーを繋いだまま、プレイヤー名の入力欄をタップする
  2. iPhoneの背面を2回叩く
  3. 画面のキーボードが出るので、名前を入力する
  4. 入力が終わったら、もう一度背面を2回叩いて元に戻す

AssistiveTouchがオンのあいだは画面に丸いボタンが表示されますが、そのままでも試合の入力に支障はありません。気になるときは背面を2回叩いて戻してください。

iPad：ショートカットバーから呼び出す

iPadには背面タップがありませんが、外付けキーボードを繋いでいるときは画面の下端に細いバー（ショートカットバー）が出ます。

  1. テンキーを繋いだまま、プレイヤー名の入力欄をタップする
  2. 画面の下端に出たバーの右端にあるキーボードのアイコンを長押しする
  3. 画面のキーボードを表示するメニューが出るので、それを選ぶ

バーが出ていないときや、うまくいかないときは下の「ほかの方法」をお使いください。

ほかの方法

  • プレイヤー名を先に入力してから、テンキーを接続する。名前を決めてしまえば、試合中に文字入力を使う場面はありません
  • コントロールセンターでBluetoothを一度オフにする。テンキーの接続が切れて画面のキーボードが戻ります
  • USB接続のテンキーなら、名前を入力するあいだだけ抜いておくのが手軽です

Androidでは通常、外付けキーボードを繋いでも画面のキーボードがそのまま使えます。もし出ない場合は、「設定」→「システム」→「言語と入力」→「物理キーボード」に、画面のキーボードを表示するかどうかの設定があります（項目名や場所は機種によって異なります）。

戦績を見る

試合結果は保存され、各セットの投擲内容まで振り返れます。アカウントでログインしていれば、機種変更しても引き継がれます。

アプリを使う

Web ブラウザでそのまま使えます。インストールすると起動が速く、オフラインでもスコアを付けられます。

  • ブラウザで開く
  • App Store（iPhone / iPad）
  • Google Play（Android）

いずれも無料です。
